# Rahano 🧭

**Rahano** is a platform for building personalized learning paths.

It helps users define their goals and current situation, then creates a learning roadmap tailored to their needs.

## ✨ About

**Don't know where to start?**

Rahano aims to make the beginning of a learning journey simpler — from choosing a skill and identifying your current level to defining available learning time and building a clear roadmap.

The goal is to help users avoid getting lost between countless resources and learning paths, and instead understand **what their next step should be**.

## 🚀 Current MVP

The current version includes:

* Landing Page
* Multi-step Onboarding
* Learning Goal Selection
* Interest Selection
* Current Skill Level
* Learning Time
* Initial Roadmap Generation
* Learning Dashboard

## 🎯 Project Goals

* Build personalized learning paths
* Make starting a new skill easier
* Provide clear and practical roadmaps
* Create a simple and intuitive user experience
* Build a scalable foundation for future development
